Void Front · build planner

Tech tree

Pick a class when you drop in, then buy five A-or-B tiers with XP from kills, damage, healing and capturing or defending points. Stat upgrades cost shards, climb in price each level, and reset when tier 3 swaps your hull. Mix and match tiers and upgrades below and the stat deck shows what the build adds up to, compared with the bare base hull. Tiers are bought in order, so picking a later tier fills earlier empty ones with option A (dashed).
